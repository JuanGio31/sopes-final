# REDXela — Centro de Distribución

Simulación de un centro de distribución con concurrencia, sincronización de recursos compartidos, comunicación interprocesos y resolución de deadlocks, implementada en Java 21 con interfaz gráfica Swing.

## Requisitos

- **Java 21** o superior
- **Maven 3.8** o superior

## Ejecución

```bash
cd red-xela
mvn package
java -jar target/red-xela-1.0-SNAPSHOT.jar
```
